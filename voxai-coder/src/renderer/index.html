Account
Your keys, stored in the OS keychain when available. Each is only ever sent to its own service: OpenRouter, Anthropic or OpenAI.

      

        

          
OpenRouter key
Every model call and web search is billed to this key.
Not set yet.

          
Management key optional
Adds your full account usage history. Not needed to run the agent.
Not set.

          
Anthropic key optional
Claude models then go straight to Anthropic, billed to this key, with Anthropic’s own caching and thinking. Other models still go through OpenRouter.
Not set: Claude models go through OpenRouter.

          
OpenAI key optional
OpenAI’s own models (GPT, o-series) then go straight to OpenAI, billed to this key. Other models still go through OpenRouter.
Not set: OpenAI models go through OpenRouter.

          
Nothing to save.

        

        

          
Balance
Counts down as runs spend, and is checked with OpenRouter after each run.

Usage history
What each model has cost on this key in the last 30 days.

          
Keys on this account
What each key has spent, to spot spending that is not VoxAI’s. Needs the management key.

          

        

        
Updates
Checks when the app opens, when you open Settings, and every 30 minutes.

      

    


    

      
Spending
A hard stop for each run, so a loop or a big fan-out can’t drain the account.

      

        
Limit per run
The run stops when it reaches this. Sub-agents and web searches draw from the same allowance. Typical runs on a DeepSeek Flash model cost under a cent.
$
Limit per goal
A goal (/goal) keeps starting new runs until it is met. It pauses when all its runs together reach this.
$

        
Balance
What is left on your OpenRouter account. Credits are bought on OpenRouter’s site, which opens in your browser.
—

      

    


    

      
Web search
Lets the agent find sources instead of guessing URLs. Each search is billed on top of model tokens.

      

        
Search the web
Off means the agent can only read pages it already has links to. Sub-agents follow this too.
Engine
OpenRouter’s fee for each search on that engine.
Results per search
What the agent gets back when it doesn’t ask for a number. Above 10, OpenRouter charges extra per result.

      

    


    

      
Notifications
When a session needs you for an approval or a question, and VoxAI isn’t the window in front.

      

        
Alerts

        
Card in the corner
A card above the taskbar says which project needs you and why. Allow, Deny or open the session from it. It hides after 12 seconds unless you point at it.
Use Windows’ own notification
Shows it as a Windows notification instead of the VoxAI card, so it also stays in the notification centre.
Taskbar badge
The taskbar button shows how many are waiting, and flashes when a new one comes in.

        
System tray

        
Minimize to the system tray
Minimizing hides the window to the tray icon instead of the taskbar. Click the icon to bring it back.
Close to the system tray
Closing the window keeps VoxAI running in the tray, so runs carry on. Quit from the tray icon.

      

    

    

      
Local models
Models that run on this PC: free, and nothing leaves your machine. They show in the model picker under “This PC”, and make a good free coder in Team.

Folders

        

        
Downloads go to the first folder, and the engine lives there too. Keep models on your fastest drive: an NVMe loads a model about half as fast again as a hard drive. ModelMaker offload plans (.offload.json) beside a model are used when it loads.

      

    

    

      
Sub-agents
Workers the agent can hand self-contained jobs to. They report back and share the run’s spending limit.

      

        
Model
A cheaper model makes fan-outs cheaper. Leave empty to use the session’s model.
Turns before answering
How many tool steps a worker may take before it must report.
turns
Time limit
A worker still running after this is stopped and returns what it has.
sec

        
Every run

        
Eyes for models that cannot see
When the session’s model cannot read images, this model looks at each screenshot and describes it, problems included.
Keep the cache for an hour
The model keeps the earlier part of the conversation cached for 5 minutes, so after a break the next message pays full price to send it again. This keeps it for an hour on models that allow it. Caching costs a little more, but it outlasts a break.

      

    


    

      
Context
How much of the session the model sees with each request, and when older parts are summarised to make room. The defaults suit almost everyone.

      

        

          

          
0

          
Instructions and toolsThis sessionSummarises older turnsMust summarise

          

        

        

          
Context size
Bigger remembers more of a long session, but every step sends more, so it costs more and runs slower.
tokens

          
Summarise older turns at
When the session fills this much, its early turns are folded into a summary that keeps what you asked for and what is done.

          
Must summarise at
A safety net: past this, the summary is made before the next request goes out. Always above the first.

        

        
Tool output

        

          
Longest tool output kept
A longer result, like a big build log, keeps its start and end, with the middle marked as cut.
chars

        

        
Setting these before launch
Each can also come from an environment variable: VOX_CONTEXT_LIMIT, VOX_COMPACT_THRESHOLD, VOX_HARD_LIMIT_FRACTION, VOX_TOOL_RESULT_MAX_CHARS.

      

    

    

      
Memory
What the agent has chosen to remember about this project. It reads these at the start of every run, so remove any that are wrong or out of date.

      

        
No project open

        
        

        
The agent saves a fact when it learns something worth keeping: a convention, a decision, where things live. You can also ask it to remember something. Facts are kept in the project, in .voxai/memory.json.

      

    

    

      
Skills
Instructions the agent loads when a task needs them: how to use a tool, a service or the preview browser. It sees each skill’s one-line description at the start of every run, and loads the whole skill when a task calls for it.

      

        
No project open

        
A folder with a SKILL.md to fill in, opened in your editor.

        
        

        
A skill is a folder with a SKILL.md that starts with a name: and a one-line description: between --- lines. Yours apply to every project; a project’s own go in its .voxai/skills folder. Skills in Claude Code’s and Codex’s folders are read too.

      

    

    

      
Apps (MCP)
Let Vox use other programs: a browser, Windows apps, Blender, Figma. An app starts on this PC the first time a run needs it, and Vox asks before using it unless it has full access.

      

        
Your apps

        

        
Add an app

        

        
Most apps start with npx, which comes with Node.js, or uvx, which comes with uv. An app on the web, with a URL instead of a command, can be reached through npx -y mcp-remote <url>. The first start downloads the app, so it can take a minute.
